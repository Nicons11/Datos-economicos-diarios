# Conectar Drive con Apps Script, sin cliente OAuth ni tarjeta

Esta opción sustituye la creación de un cliente OAuth en Google Cloud. La autorización se hace en Apps Script una sola vez. Se aplican las cuotas gratuitas de Google; una cuenta administrada puede restringir aplicaciones web públicas.

1. En el proyecto nuevo de Apps Script, cambiá «Proyecto sin título» por **Excel diario BNA**.
2. Abrí `Codigo.gs` de esta carpeta en GitHub y usá **Copy raw file** para copiar su contenido. En el editor de Apps Script, borrá `function myFunction() { ... }` y pegá el código completo. Guardá con el icono de disquete o Ctrl+S / Cmd+S.
3. Arriba, en la lista de funciones, elegí **prepararConexion** y pulsá **Ejecutar**. Pulsá **Revisar permisos**, elegí la cuenta que tiene acceso a la carpeta de Drive y autorizá. El código usa Drive para leer y actualizar el Excel y permite solicitudes externas para guardar el binario conservando su enlace. No autorices un proyecto cuyo contenido no reconozcas. Google puede mostrar un aviso de aplicación sin verificar porque es tu propio proyecto; solo continuá si verificaste ese proyecto y el código. Si tu organización lo bloquea, no intentes eludir la restricción.
4. Pulsá **Implementar → Nueva implementación**. En el engranaje elegí **Aplicación web**. Ejecutar como: **Yo**. Quién tiene acceso: **Cualquier usuario** (incluidos los que no iniciaron sesión). Pulsá **Implementar** y copiá la **URL de la aplicación web** que termina en `/exec`. El receptor exige una firma privada en cada solicitud; conocer la URL no permite leer ni escribir el archivo.
5. En GitHub → repositorio → **Settings → Secrets and variables → Actions → New repository secret**, guardá esa URL como **APPS_SCRIPT_URL**.
6. En Apps Script, abrí **Configuración del proyecto** (engranaje a la izquierda), bajá a **Propiedades de la secuencia de comandos** y copiá el valor de **CLAVE_GITHUB**. Guardalo en otro secreto GitHub llamado **APPS_SCRIPT_KEY**. No lo pegues en el chat, en el código ni en una variable pública.
7. Avisá que terminaste. Se puede lanzar el workflow completo desde Actions y comprobar el archivo de la carpeta. No hace falta configurar `GOOGLE_DRIVE_CREDENTIALS_JSON` para esta opción. Las siguientes actualizaciones ocurren en GitHub aunque la Mac esté apagada.

La carpeta está fijada en el código y solo se acepta `Tipo_de_Cambio_BNA.xlsx`. Las solicitudes llevan firma HMAC, fecha y un identificador; se rechazan firmas inválidas, solicitudes vencidas y repeticiones conservadas en la caché. Apps Script aplica cuotas antes de ejecutar el código, por lo que no publiques innecesariamente la URL. Para revocar la conexión, archivá la implementación o eliminá su clave. Si modificás el código, actualizá la implementación a una versión nueva.

El programa descarga primero la versión de Drive, consulta Errepar y solo después envía el libro validado. Conserva el ID del archivo existente. Se comprueba la fecha de modificación antes de escribir; evitá editar simultáneamente porque esa comprobación no bloquea cambios hechos desde Drive. No se ha validado el despliegue real hasta que el usuario complete la autorización y la implementación.
